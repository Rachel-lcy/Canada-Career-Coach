# Canada Market Notes

Background for the coach. **Rules change.** Treat everything here as a starting point: before stating a rule as current, check the official source and tell the user the date you checked.

Last reviewed by the maintainer: November 2026.

## Resume conventions

- Called a "resume". "CV" is used for academic and some medical roles.
- One to two pages, letter size (8.5 × 11 in).
- Leave out photo, date of birth or age, marital status, gender, religion, nationality and SIN.
- City and province is enough for an address.
- Volunteer experience is valued and can have its own section.
- References are usually given on request, not listed on the resume.

## Requirement phrases and their usual level

| Phrase in posting                                                | Usual level                                  | Notes                                                                    |
| ---------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------ |
| "Canadian citizens only", "citizens or permanent residents only" | Hard blocker                                 | Common in some government, defence and security roles                    |
| "Must be legally entitled to work in Canada", "no sponsorship"   | Hard blocker if the user lacks authorization | The employer will not support a work permit                              |
| "Must hold Secret / Top Secret clearance"                        | Hard blocker if not held                     | Held now, not obtained later                                             |
| "Must be able to obtain Reliability Status"                      | Pre-start condition                          | Usually done after an offer                                              |
| "Bilingual imperative", "BBB/BBB", "CBC/CBC"                     | Hard blocker if not met                      | Federal second-language level                                            |
| "French an asset"                                                | Flexible                                     |                                                                          |
| "Valid Class 5 driver's licence" (Alberta) or equivalent         | Hard blocker if not held                     | Check the class named                                                    |
| "Reliable vehicle", "own transportation"                         | Logistics                                    | Compare with the user's profile                                          |
| "Police information check", "vulnerable sector check"            | Pre-start condition                          | Obtained from the local police service. Never ask about criminal history |
| Regulated title (P.Eng., CPA, RN, journeyperson)                 | Hard blocker if not held                     | Provincial licence or designation                                        |
| "Degree or equivalent experience", stated equivalency            | Flexible                                     | Apply the equivalency before marking a gap                               |
| "Preferred", "an asset", "nice to have"                          | Flexible                                     |                                                                          |

If a posting does not mention work authorization, record it as **Not stated** and suggest checking the application page.

## Pay formats

- Public-sector postings often state pay **bi-weekly** with an annual equivalent and a classification (for example "Technologies 6"). Use the annual figure when one is given.
- Part-time and hourly roles state pay per hour, sometimes with different rates for different work.
- Unionized roles follow a collective agreement; the pay grid is often public.

## Provincial differences

- **Pay transparency.** Some provinces require salary ranges in public job postings (for example British Columbia, and Ontario for larger employers from 2026). Rules differ in scope and date. Check the current rule for the posting's province.
- **Employment standards** (overtime, holidays, notice) are provincial for most employers and federal for federally regulated sectors such as banks, telecom and airlines.
- **French.** Quebec employers and many federal roles require French; flag it rather than assessing French documents.

## Alberta and Calgary (example province)

- Wage data: alis (Alberta Learning Information Service) wage and salary survey; Job Bank wages for the Calgary region.
- Large employer sectors: energy, technology, health, municipal and provincial government, post-secondary.
- Government of Alberta postings show the classification and bi-weekly pay range.
- Police information checks in Calgary are issued by the Calgary Police Service.
- Settlement and employment agencies offer free resume reviews; suggest the user look for one.
