# Keyword Library

Starting banks of terms by role track. They are **seeds, not a verified list**: confirm each term against the actual postings you are targeting before relying on it, and add only terms you can truthfully support.

## Track A: Web development (junior and front-end)

Typical settings: digital agencies, in-house marketing and web teams, startups, post-secondary institutions, municipalities, nonprofits.

Terms: HTML5, CSS3, JavaScript (ES6+), TypeScript, React, Vue, Next.js, Node.js, Express, REST API, JSON, responsive design, mobile-first, cross-browser testing, accessibility (WCAG 2.1, AODA in Ontario), semantic HTML, Git, GitHub, pull requests, code review, agile, Jira, Figma, UI/UX collaboration, WordPress, CMS, SEO basics, performance optimization, unit testing, deployment (Netlify, Vercel, AWS), portfolio.

Coaching note: junior candidates usually have project experience, not paid experience. Name each project's type honestly (capstone, personal, volunteer, freelance) and link a live demo or repository where possible. Do not turn "built a React project" into "professional React experience".

## Track B: IT support and service desk

Typical settings: managed service providers, school boards, health authorities, municipalities, corporate IT teams.

Terms: help desk, service desk, Tier 1 / Tier 2 support, incident management, ticketing system (ServiceNow, Jira Service Management, Freshservice), ITIL, SLA, troubleshooting, Windows 10/11, macOS, Microsoft 365, Active Directory, Microsoft Entra ID, Intune, account provisioning, password resets, hardware imaging, printers and peripherals, remote support, VPN, TCP/IP, DNS, DHCP, knowledge base articles, customer service, escalation.

Coaching note: home labs and volunteer tech support are real evidence when described honestly ("configured in a home lab", not "managed in production").

## Track C: Project coordination and PMO

Typical settings: corporates, consultancies, public bodies, construction and energy firms.

Terms: project lifecycle, project coordination, project schedule, status reporting, risk register, issue log, change control, stakeholder management, meeting minutes, budget tracking, resource planning, Gantt, agile, scrum, Jira, MS Project, Smartsheet, Power BI, PMP, CAPM.

Coaching note: name tools only if genuinely used. Coordination evidence from any country counts; explain context a Canadian reader may not know.

## Track D: Business and data analysis

Typical settings: banks, insurers, energy firms, government, consultancies.

Terms: requirements gathering, business case, process mapping, gap analysis, stakeholder interviews, user stories, acceptance criteria, data analysis, Excel, SQL, Power BI, Tableau, KPIs, dashboards, reporting, recommendations.

Coaching note: check that the resume shows both the analysis and what changed because of it.

## Adding your own track

Add a section per role family you target: typical settings, 15–25 terms taken from real Canadian postings, and a one-line coaching note on common gaps. Job Bank and provincial career sites list the common duties for each occupation (NOC code) and are a good place to check vocabulary.

## ATS optimization rules

1. Mirror the posting's wording where the user genuinely has the experience; do not paraphrase a specific term away.
2. Place the highest-priority terms in the first three bullets of each relevant role.
3. In a skills section, list only tools and methods actually used.
4. Avoid keyword stuffing. Modern systems and human readers both look for context.
5. Use a simple layout (no tables, text boxes or images for key content) unless the employer says otherwise; common Canadian ATS platforms include Workday, Taleo, SuccessFactors and Greenhouse.
6. Submit in the format the employer requests; if none is stated, check the application page, since requirements differ.
